# FettyTools

**Interactive educational tools for creating quizzes, learning activities, and reusable teaching content.**

FettyTools is a collection of browser-based educational tools developed by Jason Fetty, a librarian with experience in information literacy instruction, educational technology, and interactive learning content.

## Quiz Builder

The FettyTools Quiz Builder enables educators, librarians, and instructional designers to create interactive quizzes without programming knowledge.

### Features

- Create interactive quizzes using five question types:
  - Multiple choice (one answer)
  - Multiple answers (checkboxes)
  - True / False
  - Fill in the blanks
  - Mark the words (click text)
- Edit and organize questions through a visual interface.
- Preview quizzes from the student's perspective.
- Save and reload quiz projects using JSON files.
- Export standalone HTML quizzes.
- Embed exported quizzes in websites and learning guides.
- Run quizzes locally without requiring an account or server.

## Getting Started

1. Open the Quiz Builder in your browser.
2. Create questions and configure your quiz.
3. Save your project as JSON for future editing.
4. Export the finished quiz as HTML.
5. Share the HTML file or embed it in your educational content.

## Project Goals

FettyTools aims to make interactive educational content easier to create, customize, and distribute, particularly for educators who do not have access to specialized authoring software.
